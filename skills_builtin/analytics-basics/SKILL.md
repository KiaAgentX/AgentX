# سواد تحلیل برای فروشنده

## ۵ عددی که هر هفته باید ببینی
1. **بازدید → خرید (تبدیل):** زیر ۲٪؟ مشکل قیمت یا توضیح محصول است
2. **میانگین سبد (AOV):** با باندل بالا ببرش، با تخفیف عمیق نبرش
3. **مشتری تکراری:** بالای ۲۵٪ = موتور رشد سالم
4. **محصول مرده:** ۳۰ روز بدون فروش → قیمت را بشکن یا بایگانی کن
5. **هفتهٔ هم‌روش:** از پنل ادمین، نمودار «تحلیل روژن» را هفته‌ای یک‌بار ببین

## قانون تصمیم
عدد بدون اقدام، تفریح است. برای هر عدد یک آستانه بگذار:
«اگر تبدیل < ۲٪ شد → توضیحات و پیش‌نمایش را بازنویسی کن.»

## تله‌های رایج
- غرور به بازدید بالا: بازدید بدون فروش = ویترین خیس، عابر کسی نمی‌ایستد
- قضاوت با دادهٔ یک روزه — همیشه هفته را ببین
